# Математические паспорта девяти инвариантов (`v1.0`)

**Модуль реализации:** `src/math/GeometryValidators.ts` (`validateInvariants`, допуск по умолчанию `DEFAULT_TOLERANCE = 1e-9`)  
**Идентификаторы:** Сохранены все 9 исходных `id` без изменений.

---

## Классификация инвариантов по характеру проверки

| Категория | Идентификаторы (`id`) | Характер проверки |
|---|---|---|
| **Координатно-геометрические** | `sides_equality`, `opposite_angles`, `orthogonal_diagonals`, `guiding_parallelism` | Проверяют геометрию напрямую по координатам вершин $A, B, B', A', D_a, D_b$. |
| **Гибридные (независимое построение + аналитика)** | `parallelogram_identity`, `area_consistency`, `supplementary_angles` | Сверяют координатно-векторные измерения (расстояния `hypot`, шнуровая площадь, `atan2`) с аналитическими полями `calc`. |
| **Частично независимые** | `ratio_invariant` | Сверяет геометрическое отношение $h_r/c$ (и $S_r/S_c$) с аналитической мерой асимметрии $1/\sqrt{1+A^2}$. |
| **Диагностические / алгебраические** | `reciprocal_compensation` | Проверяет тождество $\eta_S \cdot \eta_L = 1$ и перекрёстно $(h_r/c) \cdot \eta_L = 1$ (не проверяет координаты вершин $A', B'$). |

---

## Паспорт 1: `sides_equality`
1. **Название и ID:** Равенство четырёх сторон (`sides_equality`).
2. **Геометрический смысл:** Замкнутый четырёхугольник $ABB'A'$ является равносторонним со стороной $c = |AB|$ (необходимое условие ромба).
3. **Математическая формула:** $\|B - A\| = \|B' - B\| = \|A' - B'\| = \|A - A'\| = c$.
4. **Исходные данные из `calc`:** `triangle.A`, `triangle.B`, `A_prime`, `B_prime`, `sideLength` ($c$).
5. **Независимость от Path A:** **Высокая** (координатная). Длины сторон считаются независимо через `Math.hypot(dx, dy)` по координатам вершин и сравниваются с `sideLength`.
6. **Возможные общие источники ошибок:** Если и `sideLength`, и вектор сдвига в `A_prime`/`B_prime` одновременно масштабированы с одним неверным коэффициентом $k \ne 1$, то равенство $|BB'| = |A'A| = kc$ пройдёт, хотя $|AB| = c \ne kc$ всё равно поймает расхождение; синхронное искажение всех вершин $A, B, A', B'$ и $c$ в $k$ раз не обнаруживается.
7. **Нормированная невязка:** $\delta_1 = \frac{1}{c} \max\big(\big||AB|-c\big|, \big||BB'|-c\big|, \big||B'A'|-c\big|, \big||A'A|-c\big|\big)$.
8. **Допустимый допуск:** $\delta_1 < 10^{-9}$ (фактический машинный шум $\sim 0 \dots 2 \times 10^{-16}$).
9. **Границы применимости:** $0 < c < \infty$ (требует `Number.isFinite(c) && c > 0`). Устойчив до $a, b \sim 10^{307}$ (до переполнения $A'_y, B'_x$).
10. **Что обнаруживает:** Сдвиг любой из вершин $A, B, A', B'$, неверную длину сдвига $L \ne c$, расхождение между `triangle.c` и координатами $A, B$.
11. **Что принципиально не обнаруживает:** Превращение ромба в параллелограмм другого угла при сохранении длин сторон (если бы $\vec{e}$ был повернут на другой угол $\theta \ne 45^\circ$, стороны всё равно остались бы равны $c$, что ловится инвариантами `opposite_angles` и `guiding_parallelism`).

## Паспорт 2: `supplementary_angles`
1. **Название и ID:** Сумма соседних углов (`supplementary_angles`).
2. **Геометрический смысл:** Внутренние углы при смежных вершинах $A$ и $B$ дают в сумме развёрнутый угол $180^\circ$ (свойство параллельности $AA' \parallel BB'$ в выпуклом обходе).
3. **Математическая формула:** $\varphi_A + \varphi_B = 180^\circ$.
4. **Исходные данные из `calc`:** `phiA_deg`, `phiB_deg`, а также координаты `triangle.A`, `triangle.B`, `A_prime`, `B_prime`.
5. **Независимость от Path A:** **Гибридная.** Половина проверки (`angleSumAnalytical`) — алгебраическая тавтология ($\alpha + \beta = 90^\circ \implies 45^\circ+\beta + 45^\circ+\alpha = 180^\circ$), но вторая половина (`angleSumCoord = phiA_vec + phiB_vec`) вычисляется независимо по координатам через `interiorAngleCCWDeg`.
6. **Возможные общие источники ошибок:** Если `AA'` и `BB'` параллельны, но повернуты на произвольный угол $\theta \ne 45^\circ$ (и при этом сохраняют CCW-выпуклость), сумма $\varphi_A^{\text{vec}} + \varphi_B^{\text{vec}}$ всё равно равна $180^\circ$.
7. **Нормированная невязка:** $\delta_2 = \frac{1}{180^\circ}\max\big(|\varphi_A^{\text{ana}} + \varphi_B^{\text{ana}} - 180^\circ|,\; |\varphi_A^{\text{vec}} + \varphi_B^{\text{vec}} - 180^\circ|\big)$.
8. **Допустимый допуск:** $\delta_2 < 10^{-9}$.
9. **Границы применимости:** Невырожденные рёбра ненулевой длины, конечные координаты вершин.
10. **Что обнаруживает:** Непараллельность $AA'$ и $BB'$, переворот ориентации (если одно из слагаемых становится $> 180^\circ$), ошибку в `alphaRad + betaRad`.
11. **Что принципиально не обнаруживает:** Нарушение длин $L \ne c$, изменение направления направляющих $AA' \parallel BB'$ с $+45^\circ$ на другой общий угол, а также ошибку в противоположных вершинах $A', B'$ при условии, что $\vec{AA'} \parallel \vec{BB'}$ (например, трапецию с параллельными боковыми сторонами $AA' \parallel BB'$).

## Паспорт 3: `opposite_angles`
1. **Название и ID:** Равенство противоположных углов (`opposite_angles`).
2. **Геометрический смысл:** Противолежащие внутренние углы при вершинах $(A, B')$ и $(B, A')$ равны в выпуклом обходе $A \to B \to B' \to A'$.
3. **Математическая формула:** $\varphi_A = \varphi_{B'}$ и $\varphi_B = \varphi_{A'}$.
4. **Исходные данные из `calc`:** Координаты `triangle.A`, `triangle.B`, `A_prime`, `B_prime`, а также скалярные поля `phiA_deg`, `phiB_deg`, `phiB_prime_deg`, `phiA_prime_deg`.
5. **Независимость от Path A:** **Координатно-геометрическая (высокая).** Все 4 угла $\varphi_A^{\text{vec}}, \varphi_B^{\text{vec}}, \varphi_{B'}^{\text{vec}}, \varphi_{A'}^{\text{vec}}$ вычисляются независимо по парам нормированных исходящих векторов через `interiorAngleCCWDeg` и сравниваются как между собой, так и с аналитическими полями `calc`.
6. **Возможные общие источники ошибок:** При сверхбольшой асимметрии ($b/a \gtrsim 10^{15}$) вектор $\overrightarrow{B'A'} = A' - B'$ в `float64` теряет точность малой компоненты (эффект 53-битной мантиссы).
7. **Нормированная невязка:**
   $$\delta_3 = \frac{1}{180^\circ}\max\big(|\varphi_A^{\text{vec}}-\varphi_{B'}^{\text{vec}}|,\; |\varphi_B^{\text{vec}}-\varphi_{A'}^{\text{vec}}|,\; |\varphi_A^{\text{vec}}-\varphi_A|,\; |\varphi_B^{\text{vec}}-\varphi_B|,\; |\varphi_{B'}^{\text{vec}}-\varphi_{B'}|,\; |\varphi_{A'}^{\text{vec}}-\varphi_{A'}|\big).$$
8. **Допустимый допуск:** $\delta_3 < 10^{-9}$.
9. **Границы применимости:** Невырожденные конечные координаты вершин; проверено до масштабов $10^{200}$ и асимметрии $10^{10}$.
10. **Что обнаруживает:** Искажение любой из вершин $A, B, A', B'$, самопересечение (`A' <-> B'`), рассинхронизацию скалярных полей `phiB_prime_deg`/`phiA_prime_deg` с геометрией.
11. **Что принципиально не обнаруживает:** Растяжение ромба в неквадратный прямоугольник/параллелограмм со сдвигом обеих вершин $A', B'$ на одинаковый произвольный вектор $L\vec{u}$ ($L \ne c$ или угол $\vec{u} \ne 45^\circ$), так как противоположные углы остаются равными у любого параллелограмма.

## Паспорт 4: `orthogonal_diagonals`
1. **Название и ID:** Ортогональность диагоналей (`orthogonal_diagonals`).
2. **Геометрический смысл:** Диагонали $AB'$ и $BA'$ пересекаются под прямым углом (характеристическое свойство ромба среди всех параллелограммов).
3. **Математическая формула:** $\overrightarrow{AB'} \perp \overrightarrow{BA'} \iff \frac{|\overrightarrow{AB'} \cdot \overrightarrow{BA'}|}{\|\overrightarrow{AB'}\| \cdot \|\overrightarrow{BA'}\|} = 0$.
4. **Исходные данные из `calc`:** Вершины `triangle.A`, `triangle.B`, `A_prime`, `B_prime`, а также `diagVector1`, `diagVector2`.
5. **Независимость от Path A:** **Координатно-геометрическая (высокая).** Проверяет косинус угла напрямую по разностям координат вершин и по сохранённым векторам.
6. **Возможные общие источники ошибок:** Нет общих тригонометрических формул с `Path A`; зависит только от координат вершин.
7. **Нормированная невязка:** $\delta_4 = \max\big(|\hat{d}_1^{\text{coord}} \cdot \hat{d}_2^{\text{coord}}|,\; |\hat{d}_1^{\text{stored}} \cdot \hat{d}_2^{\text{stored}}|\big)$ (косинус отклонения от $90^\circ$, полностью безразмерен).
8. **Допустимый допуск:** $\delta_4 < 10^{-9}$.
9. **Границы применимости:** Ненулевые конечные векторы диагоналей.
10. **Что обнаруживает:** Сдвиг $A'$ или $B'$, разрушающий равенство смежных сторон ромба, расхождение между `diagVector1/2` и вершинами, перестановку `A' <-> B'`.
11. **Что принципиально не обнаруживает:** Превращение ромба в **ортодиагональный четырёхугольник** (например, дельтоид при сдвиге $B'$ вдоль прямой $AB'$), а также общий поворот или масштабирование всей конструкции.

---

## Паспорт 5: `parallelogram_identity`
1. **Название и ID:** Сумма квадратов диагоналей (`parallelogram_identity`).
2. **Геометрический смысл:** Выполняется метрическое тождество параллелограмма со стороной $c$: $d_1^2 + d_2^2 = 4c^2$.
3. **Математическая формула:** $\left(\frac{d_1}{2c}\right)^2 + \left(\frac{d_2}{2c}\right)^2 = 1$.
4. **Исходные данные из `calc`:** `triangle.A`, `triangle.B`, `A_prime`, `B_prime`, `sideLength` ($c$), `d1`, `d2`.
5. **Независимость от Path A:** **Гибридная.** Часть по `calc.d1, calc.d2` проверяет внутреннюю алгебраическую согласованность формул `PythagoreanPants.ts`, а часть по `d1_coord = hypot(B'-A)`, `d2_coord = hypot(A'-B)` — независимые евклидовы расстояния между вершинами и их соответствие аналитическим `d1, d2`.
6. **Возможные общие источники ошибок:** Если `c`, `d1`, `d2` одновременно масштабированы в $k$ раз без изменения координат — поймается через `d1_coord - d1`; но если все координаты и `c` масштабированы синхронно (при $c \ne |AB|$) — поймается в `sides_equality`.
7. **Нормированная невязка:**
   $$\delta_5 = \max\!\left(\left|\left(\frac{d_1^{\text{coord}}}{2c}\right)^2 + \left(\frac{d_2^{\text{coord}}}{2c}\right)^2 - 1\right|,\; \left|\left(\frac{d_1}{2c}\right)^2 + \left(\frac{d_2}{2c}\right)^2 - 1\right|,\; \frac{|d_1^{\text{coord}} - d_1|}{c},\; \frac{|d_2^{\text{coord}} - d_2|}{c}\right).$$
8. **Допустимый допуск:** $\delta_5 < 10^{-9}$.
9. **Границы применимости:** $0 < c < \infty$, конечные координаты $A, B, A', B'$. Деление на $2c$ до возведения в квадрат исключает переполнение $c^2$ вплоть до $10^{307}$.
10. **Что обнаруживает:** Ошибку в формулах `d1`/`d2`, сдвиг вершин $A'$ или $B'$, нарушение равенства сторон параллелограмма.
11. **Что принципиально не обнаруживает:** Деформацию ромба в равнобокую трапецию или неромб с сохранением длин диагоналей (например, при повороте одной диагонали вокруг её середины с сохранением $d_1^2 + d_2^2 = 4c^2$ — это ловится в `sides_equality` и `opposite_angles`).

## Паспорт 6: `area_consistency`
1. **Название и ID:** Согласованность площади (`area_consistency`).
2. **Геометрический смысл:** Три независимых способа вычисления площади ромба — через формулу шнурования (ориентированная площадь многоугольника по координатам), через полупроизведение ортогональных диагоналей $\frac{d_1 d_2}{2}$ и через основание и высоту $c \cdot h_r$ — дают тождественный результат.
3. **Математическая формула:** $S_{\text{coord}}(ABB'A') = \frac{d_1 d_2}{2} = c \cdot h_r = S_r$.
4. **Исходные данные из `calc`:** `triangle.A`, `triangle.B`, `A_prime`, `B_prime`, `sideLength` ($c$), `d1`, `d2`, `height` ($h_r$), `areaRhombus` ($S_r$).
5. **Независимость от Path A:** **Гибридная (высокая координатная независимость).** Площадь многоугольника $S_{\text{coord}}$ вычисляется по координатам вершин (нормированных на $c$), диагонали $d_1^{\text{coord}}, d_2^{\text{coord}}$ — через `hypot`, и всё это сверяется с `d1, d2`, `height` и `areaRhombus`.
6. **Возможные общие источники ошибок:** В текущей реализации дополнительно введена строгая проверка положительности $S_r > 0, h_r > 0, d_1 > 0, d_2 > 0$ (ранее при мутации `height = -5` деление на отрицательное `heightNorm` скрывало ошибку в `Math.max`).
7. **Нормированная невязка:** Максимум относительных разностей между $(d_1/S_r)(d_2/2) - 1$, $S_{\text{diags}}/c^2$, $S_{\text{coord}}/c^2$ и $h_r/c$ (нормированных на $h_r/c$).
8. **Допустимый допуск:** $\delta_6 < 10^{-9}$.
9. **Границы применимости:** **$1.49 \times 10^{-154} \lesssim a, b \lesssim 1.34 \times 10^{154}$** (область, где $S_r = c h_r$ не переполняет `Number.MAX_VALUE` и не уходит в нулевой underflow). Вне этой области `isValid` честно принимает значение `false`.
10. **Что обнаруживает:** Ошибки в `areaRhombus`, `height`, `d1`, `d2`, искажение вершин ромба, самопересечение полигона (при `A' <-> B'` знаковая шнуровая площадь обнуляется), отрицательные значения `height` или `d1, d2`.
11. **Что принципиально не обнаруживает:** Равномерный сдвиг противоположной стороны $A'B'$ параллельно $AB$ (площадь сохраняется, длина сторон меняется — ловится в `sides_equality`).

## Паспорт 7: `ratio_invariant`
1. **Название и ID:** Отношение площади к квадрату гипотенузы (`ratio_invariant`).
2. **Геометрический смысл:** Доля площади ромба относительно площади квадрата Пифагора на гипотенузе $S_c = c^2$ равна отношению высоты к стороне и определяется только мерой асимметрии $A(t)$.
3. **Математическая формула:** $\frac{S_r}{S_c} = \frac{h_r}{c} = \eta_S = \frac{1}{\sqrt{1 + A^2}}$.
4. **Исходные данные из `calc`:** `areaRhombus`, `areaSquareHypotenuse`, `height`, `sideLength`, `etaS`.
5. **Независимость от Path A:** **Частично независимая.** Сравнивает геометрическое отношение $(S_r/S_c$ и $h_r/c)$ с показателем асимметрии $1/\sqrt{1+A^2}$, но не использует координаты вершин $A', B'$ напрямую (опирается на `areaRhombus` и `height`, которые проверяются в Паспорте 6).
6. **Возможные общие источники ошибок:** Если `height`, `areaRhombus` и `etaS` вычислены из одних и тех же неверных $a, b$, тест не заметит расхождения, но рассинхронизацию между $a,b$, $c$ и $A$ поймает.
7. **Нормированная невязка:** $\delta_7 = \max\big(|S_r / S_c - \eta_S|,\; |h_r / c - \eta_S|\big)$ (уже безразмерная).
8. **Допустимый допуск:** $\delta_7 < 10^{-9}$.
9. **Границы применимости:** $1.49 \times 10^{-154} \lesssim a, b \lesssim 1.34 \times 10^{154}$ (где $S_r, S_c \in (0, \infty)$); также требуется $S_r, S_c, h_r, \eta_S > 0$.
10. **Что обнаруживает:** Ошибку в формулах `areaRhombus`, `areaSquareHypotenuse`, `height`, `q`, `A`, `etaS`, потерю связи между геометрией и параметром асимметрии.
11. **Что принципиально не обнаруживает:** Ошибки в координатах $A', B'$ (если формулы $h_r, S_r, \eta_S$ не затронуты), поскольку работает со скалярными метриками.

---

## Паспорт 8: `reciprocal_compensation`
1. **Название и ID:** Инвариант взаимной компенсации (`reciprocal_compensation`).
2. **Геометрический смысл:** Ослабление площадной эффективности ромба ($\eta_S = S_r / S_c < 1$ при $a \ne b$) строго компенсируется ростом линейного фактора $\eta_L = \sqrt{1 + A^2} = \frac{\sqrt{2}\,c}{a + b} > 1$.
3. **Математическая формула:** $\eta_S \cdot \eta_L = 1$ и $\frac{h_r}{c} \cdot \eta_L = 1$.
4. **Исходные данные из `calc`:** `etaS`, `etaL`, `height`, `sideLength`.
5. **Независимость от Path A:** **Диагностическая (слабо независимая).** Произведение `etaS * etaL` является алгебраической проверкой $1/x \cdot x = 1$, но второе условие `(height / c) * etaL == 1` связывает линейную характеристику `etaL` с геометрическим отношением `height / c`.
6. **Возможные общие источники ошибок:** Синхронное искажение формулы $A$ в обеих величинах $\eta_S$ и $\eta_L$ не меняет `etaS * etaL`, но ловится через `(height / c) * etaL`.
7. **Нормированная невязка:** $\delta_8 = \max\big(|\eta_S \cdot \eta_L - 1|,\; |(h_r / c) \cdot \eta_L - 1|\big)$.
8. **Допустимый допуск:** $\delta_8 < 10^{-9}$.
9. **Границы применимости:** $0 < a, b < \infty$ (не зависит от $L^2$-переполнения, работает даже при $a, b = 10^{200}$ и $10^{-200}$), при условии $\eta_S, \eta_L, h_r, c > 0$.
10. **Что обнаруживает:** Рассогласование $\eta_S$ и $\eta_L$, ошибку в знаках $\eta_S / \eta_L$, расхождение между $h_r / c$ и $1/\eta_L$.
11. **Что принципиально не обнаруживает:** Деформацию вершин $A', B'$ и диагоналей $d_1, d_2$.

---

## Паспорт 9: `guiding_parallelism`
1. **Название и ID:** Направляющий механизм диагоналей (`guiding_parallelism`).
2. **Геометрический смысл:** Обе внешние диагонали $D_a A$ и $D_b B$ квадратов на катетах и обе боковые стороны ромба $AA'$ и $BB'$ сонаправлены с единичным ортом $\vec{e} = (1/\sqrt{2}, 1/\sqrt{2})$ под углом $+45^\circ$.
3. **Математическая формула:** $\angle(D_a A) = \angle(D_b B) = \angle(AA') = \angle(BB') = +45^\circ$ и $\vec{e} = (1/\sqrt{2}, 1/\sqrt{2})$.
4. **Исходные данные из `calc`:** `squareA.designatedDiagStart/End`, `squareB.designatedDiagStart/End`, `triangle.A`, `triangle.B`, `A_prime`, `B_prime`, `directionE`.
5. **Независимость от Path A:** **Координатно-геометрическая (высокая).** Проверяет реальные векторы разностей вершин квадратов и ромба через нормированный `atan2`, не читая синтетические поля `diagVectorA` / `diagVectorB`.
6. **Возможные общие источники ошибок:** Если `SquareConstruction.ts` неверно разместил квадраты целиком (например, сдвинул весь квадрат $Q_a$ параллельно), но сохранил $A - D_a = (a, a)$, тест пройдёт, но смещение `A` поймают тесты координат треугольника.
7. **Нормированная невязка:**
   $$\delta_9 = \max\!\left(\frac{|\angle(D_a A)-45^\circ|}{180^\circ},\; \frac{|\angle(D_b B)-45^\circ|}{180^\circ},\; \frac{|\angle(AA')-45^\circ|}{180^\circ},\; \frac{|\angle(BB')-45^\circ|}{180^\circ},\; \|\vec{e} - \vec{e}_{\text{ref}}\|\right).$$
8. **Допустимый допуск:** $\delta_9 < 10^{-9}$.
9. **Границы применимости:** $0 < a, b < \infty$ до границы переполнения координат $A', B'$.
10. **Что обнаруживает:** Поворот диагонали в `SquareConstruction.ts`, ошибку направления сдвига при построении $A', B'$, неверное значение `directionE`.
11. **Что принципиально не обнаруживает:** Ошибку в длине сдвига $L \ne c$ вдоль верного направления $+45^\circ$ (обнаруживается в `sides_equality`) или ошибку во внешней вершине $C_a$ квадрата $Q_a$, не участвующей в диагонали $D_a A$.
