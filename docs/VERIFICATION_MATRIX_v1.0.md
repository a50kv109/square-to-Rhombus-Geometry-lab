# Матрица верификации математических утверждений (`v1.0`)

**Используемые статусы (строго по стандарту аудита):**
- `PROVEN` — строго доказано математически (см. [`MATHEMATICAL_FOUNDATION_v1.0.md`](MATHEMATICAL_FOUNDATION_v1.0.md));
- `NUMERICALLY VERIFIED` — подтверждено численными экспериментами в допустимом диапазоне;
- `TESTED` — проверено автоматизированными тестами (`npm test` → `src/tests/geometry.test.ts`);
- `CONJECTURE` — гипотеза, не доказанная в рамках `v1.0`;
- `UNVERIFIED` — не проверено / не реализовано;
- `FALSE` — опровергнуто (включая обнаруженные дефекты реализации и неверные формулировки).
